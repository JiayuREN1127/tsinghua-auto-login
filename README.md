# 清华自动登录 Chrome 插件

自动完成清华大学统一身份认证（id.tsinghua.edu.cn）登录，免去反复手动输入。

## 功能

- 自动填写用户名和密码，并复用页面原生 `$.submitForm()`（正确处理 SM2 加密、指纹采集、信任浏览器勾选逻辑）
- 登录页出现图形验证码时自动识别；识别失败自动刷新重试 3 次，仍失败则聚焦输入框并提示手动输入
- 默认无验证码时全程无人值守
- 60 秒防重复触发冷却，避免登录失败后死循环
- 密码仅保存在本机 `chrome.storage.local`，不同步云端

## 安装

1. 下载本仓库代码（或 `git clone`）
2. 打开 Chrome，访问 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本目录
5. 点击扩展图标，填入用户名和密码，保存

## 使用

- 访问任意需要清华统一认证的页面（如 info.tsinghua.edu.cn），跳转到登录页时自动登录
- 若页面要求图形验证码：插件先尝试自动识别，失败后验证码框会高亮，手动输入 4 位后自动提交
- 在扩展弹窗中可随时关闭自动登录或清除账号密码

## 技术说明

- `background.js`：监听 `tabs.onUpdated`，在登录页加载完成时通过 `chrome.scripting.executeScript` 注入 `AUTO_LOGIN_MAIN`（`world: "MAIN"`，可访问页面 jQuery）
- 验证码识别：彩色前景分割（背景近灰白）+ 列投影切分字符 + 多字体模板匹配；配合页面自带 `checkCaptcha` 接口校验，识别错误自动重试
- 页面结构参考 `/authserver/login`：`#username`、`#password`、`#sm2pass`、`#i_code`、`#captcha`

## 安全说明

密码存储在浏览器本地存储，仅用于向清华认证服务器提交登录。请勿将本插件用于未授权的自动化行为，遵守清华网络使用规范。
